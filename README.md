# 思维练习室

四类思维能力的自适应练习网站，支持 GitHub Pages。设置总时长后，依次练习图形规律、记忆能力、空间推理、文字推演，采用 20∶10∶15∶15 的模拟训练配比，默认总时长 60 分钟；其他总时长按比例缩放。这是训练方案，不代表官方考试安排。

- 网站：https://kolafish.github.io/cognitive-practice/
- 默认「北中主练」包含 1,644 道固定练习题（图形 80、折纸孔位 512、文字 1,052）和三种原创随机视觉记忆。其中 36 道原创词语类比补充 6–8 档。
- 「拓展练习」保留原有 5,598 道题（图形 300、记忆 63、空间 2,080、文字 3,155），不限制年龄或难度。
- 输入用户名即可使用本地个人档案，无需密码或验证；中文、字母、数字等1–24字符，英文字母不区分大小写，全角兼容归一化。不同用户的记录、偏好与未完成进度独立保存。
- 新用户每种小题型从1档开始；后续练习沿用该用户最后的档位，主练与拓展分别保存。答对升一档，答错或跳过降一档，范围1–8档。
- 按用户严格排除已出固定题及同情境变式，随机记忆按图案或序列内容避重；再从未见题中选择最近档位。新题用尽会提示，由用户主动开启本段复习，不自动循环重复。
- 60 分钟分为 20、10、15、15 分钟；90 分钟分为 30、15、22 分 30 秒、22 分 30 秒。
- 主练记忆：位置记忆、图案辨认、对称判断。整幅图同时展示 1 秒，之后作答；各档改变网格、标记数量或干扰差异，不缩短展示时间。生成刺激和答案完整保存。
- 主练动画折纸由孔数填空改成孔位四选一，使用同孔数、同孔形和大小的干扰图，并统一答案纸张的裁切范围。
- 每段到时自动进入下一类；暂停停止计时。刷新或重新打开页面后可恢复暂停的进度。
- 训练积分按实际出题档位计分：答对得档位×10分，其余0分，新题、复习、历史回算分开显示。积分为奖励规则，跨题型尚未校准，不能当统一能力分；详见 [计分说明](docs/scoring.md)。
- 浏览器本地记录练习日期、模式、实际用时、四类统计、逐题答案、训练积分和小题型档位变化；支持按日期、答对/答错筛选及 JSON 导出/导入。

## 本地运行

需要 Node.js 22+ 和 Python 3，无第三方运行依赖。自动测试使用开发依赖 fake-indexeddb 验证本地数据库迁移与用户数据隔离。

```sh
npm run dev
```

打开 http://127.0.0.1:4173/ 。正式网站和本地预览属于不同的浏览器存储区域，记录可通过导出、导入迁移。

```sh
npm ci
npm run check
npm test
npm run build
```

构建输出在 `dist/`。推送 `main` 后，GitHub Actions 检查、测试并部署到 GitHub Pages。仓库设置的 Pages 发布来源应为 GitHub Actions。

## 记录与备份

用户档案和记录存放在当前站点、当前浏览器的 IndexedDB；每个用户的进度检查点和偏好分别存放在 localStorage。相同用户名只在同一浏览器、同一站点内对应同一用户；不同浏览器或设备需要导入备份，不会自动同步。练习记录不会上传到服务器，也不会提交到 Git 仓库。清除浏览器站点数据会清除记录，请定期在“练习记录”中导出备份。

v1、v2 记录和未完成练习保留创建时的计时、题库和自适应规则。新建 v3 练习保存模式、各小题型目标档位及实际呈现题目的快照，后续调整主练筛选也不影响逐题回看；支持混合导入新旧记录。

新备份包含当前用户名、完整去重清单、各小题型最后档位和选中的练习记录（含逐题积分）；即使导出单次记录，也携带完整个人进度。导入按用户名、记录ID和更新时间合并，不清空已有记录，不覆盖其他用户的同ID记录。删除练习详情仍保留个人档位和去重清单。

旧记录升级后先保留为“未归属记录”，可先查看，再明确归入某个用户；不会自动归给第一个输入的名字。旧版未完成练习的题目、答案、计时规则和已用时间保持不变。

有矩阵题包时，进入用户名档案，从首页的「矩阵补充练习」导入 JSON，回到首页选择「北中主练」。题包留在当前浏览器。图形段优先使用同档原题；4 档原题用完时可出第 4 档变式，变式计复习积分，且不调整个人档位。Sandia 保留原八选一，通常每四道其他图形题穿插一道，独立记录用时、对错和未答，不计入总体正确率或训练积分。也可在补充练习页面单独练，两边共享已见题去重，记录可分别导出。主练备份可跨设备查看结果，题图需另外导入同一题包。题包素材须随文件单独交付，勿放入 `public/` 或 Git 仓库。

总时长可设置为 4–180 分钟。实际用时不包含暂停或关闭网页的时间，跳过、未答与答错分别统计。

## 题库与难度

1–8 档是按原始难度、题目结构和启发式规则估算的练习档位，未经过统一心理测量校准，不代表年级、年龄常模或智商分数。每道题均保留原始难度、来源及分档依据。它是通用能力练习，不是北京中学官方试题或选拔结果预测。

主练筛选依据、分档方式和排除统计见 [主练题库](docs/practice-bank.md)。矩阵构图、数字与位置序列、字母绑定、旋转、立方体、动画孔数及未经主练审入的词语题保留在拓展库。拓展和旧版记忆固定题用尽后，可生成位置序列题。

许可、署名及改编说明见 [题库来源](public/attributions.html)、[导出统计](docs/bank-export.md) 和 `public/licenses/`。缺少明确再分发许可的 51 道 ACCES 题未发布。保留原始数据的本地研究项目不包含在本仓库中。

题库重新导出：

```sh
python3 scripts/build-bank.py --source /path/to/beijing-academy-carnival-research
python3 scripts/build-practice-bank.py
```

## 目录

```text
public/engine.js       计时、自适应选题、判题、记录格式
public/practice.js     题型分组与原创视觉记忆生成
public/profiles.js     用户档案、跨练习去重与个人难度衔接
public/scoring.js      版本化训练积分与分题型、分档统计
public/storage.js      浏览器存储与备份合并
public/app.js          界面与交互
public/data/           标准化题目与清单
public/assets/bank/    题目图像和视频
scripts/              构建与题库导出
tests/                计时、判题、备份和题库完整性检查
```
