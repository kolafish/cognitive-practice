# 思维练习室

四类思维能力的自适应练习网站，支持 GitHub Pages。设置总时长后，依次练习图形规律、记忆能力、空间推理、文字推演，各占四分之一时间。

- 网站：https://kolafish.github.io/cognitive-practice/
- 题库：5,598 道（图形 300、记忆 63、空间 2,080、文字 3,155），不限制年龄。
- 四类各自从 1 档开始，答对升一档，答错或跳过降一档，范围 1–8 档。缺少相应档位时选择最近档位，优先避免重复题及重复情境。
- 每段到时自动进入下一类；暂停停止计时。刷新或重新打开页面后可恢复暂停的进度。
- 浏览器本地记录练习日期、实际用时、四类统计、逐题答案和档位变化；支持按日期、答对/答错筛选及 JSON 导出/导入。

## 本地运行

需要 Node.js 22+ 和 Python 3，无第三方运行依赖。

```sh
npm run dev
```

打开 http://127.0.0.1:4173/ 。正式网站和本地预览属于不同的浏览器存储区域，记录可通过导出、导入迁移。

```sh
npm run check
npm test
npm run build
```

构建输出在 `dist/`。推送 `main` 后，GitHub Actions 检查、测试并部署到 GitHub Pages。仓库设置的 Pages 发布来源应为 GitHub Actions。

## 记录与备份

记录存放在当前站点、当前浏览器的 IndexedDB；进度检查点和偏好存放在 localStorage。练习记录不会上传到服务器，也不会提交到 Git 仓库。清除浏览器站点数据会清除记录，请定期在“练习记录”中导出备份。

导入按记录 ID 和更新时间合并，保留较新版本，不清空已有记录。总时长可设置为 4–180 分钟。实际用时不包含暂停或关闭网页的时间，跳过、未答与答错分别统计。

## 题库与难度

1–8 档是按原始难度、题目结构和启发式规则估算的练习档位，未经过统一心理测量校准，不代表年级、年龄常模或智商分数。每道题均保留原始难度、来源及分档依据。它是通用能力练习，不是北京中学官方试题或选拔结果预测。

图形、组合构图、顺序记忆、位置绑定、空间选择、折纸动画和文字推理使用不同判题器。部分空间题保留必须参考的英文原文；折纸动画仅判断总孔数。记忆固定题用尽后，可生成位置顺序题，生成内容完整保存到记录中。

许可、署名及改编说明见 [题库来源](public/attributions.html)、[导出统计](docs/bank-export.md) 和 `public/licenses/`。缺少明确再分发许可的 51 道 ACCES 题未发布。保留原始数据的本地研究项目不包含在本仓库中。

题库重新导出：

```sh
python3 scripts/build-bank.py --source /path/to/beijing-academy-carnival-research
```

```text
scripts/              构建与题库导出

```
