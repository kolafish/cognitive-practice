# 本地图形规律题包

进入自己的用户名档案，在首页点击「导入图形规律题包」，选择单独交付的 JSON 文件，继续选择「北中主练」。导入后的题目直接参与图形段选题。它们不需要另开一个练习模式。

题包与个人进度分别存储：题包在 IndexedDB 的 `cognitive-practice-figures` 数据库，按用户隔离；去重、难度和题目快照沿用个人档案。重复导入同一文件不重复增加题目。同名但内容改变的题包、与其他题包重复的题目会被拒绝，原内容保留。新增题应另交付不重叠的补充包。原 MaRs / Sandia 导入方式和存储不变。

四个题族 `figure-position`、`figure-style`、`figure-attribute`、`figure-quantity` 分别从1档开始，答对升档，答错或跳过降档，最高4档。图形段在可用题族间均衡轮转，再按各题族最近的未见档位抽题。MaRs仍沿用自己的档位；已用尽的第4档原题可按原规则补变式，Sandia仍穿插且单独统计。新题族的档位按结构估计，未与MaRs或年龄常模校准。

北中主练中，普通新增规律题答错后，下一题优先安排一道同规律的未见题，再恢复正常轮换；这一次巩固优先于Sandia穿插。匹配按 `ruleIds` 的首个主规律标签，例如封闭区域计数或交点，不能只因同属“数量规律”就视为匹配。先选最接近答错后目标档位的题，同等距离取较低档，再优先匹配原题更多规律、减少新增规律。若同档和低档均无题，可使用最近的较高档。没有同规律未见题则正常选题，不重复原题或生成新题。

巩固题只追加一次，答错、跳过后都不连续追加；答对、跳过、到时未答、主动复习和其他题型不触发。图形段到时仍立即换段，不增加总时长。巩固题仍是新题，照常计分、调档及去重。`questionSnapshot.ruleReinforcement` 保存版本、触发错题ID及共同规律标签，暂停、刷新、导出导入后保留这一关联；旧记录没有该字段也能正常读取。已导入的200题包无需重新导入。

作答前显示原图和固定A–D选项；作答后显示正确答案、中文规律类型和解题思路。解析随练习快照保留，错题回看也可见。积分继续按实际档位×10奖励，不能作为跨题族的统一能力分。

## 文件约束

- `format: cognitive-practice-figure-pack`，`version: 1`。
- 顶层 `id`、`name`、`questions` 与 `images`；最多1000题，文件上限32 MiB。
- 每题保留来源ID、HTTPS来源地址、四个选项、A–D答案、四类题族之一、1–4档、受支持的规律标签和中文解析。
- 只接收 `reviewStatus: image-and-answer-reviewed` 的题目。此字段是制包者的审查声明，导入程序不具备自动证明答案正确的能力。
- 图像仅接收内嵌PNG，检查签名、尺寸和解码结果；不加载题包中的远程图像或可执行内容。图片通过当前用户的Blob URL显示，不上传。
- 在完整校验通过后原子写入。格式错误、重复题、储存失败均不覆盖原记录。

题包文件与练习备份都应保留。练习备份不含图片：换设备先导入个人记录，再在对应用户名下导入题包，即可恢复图像、去重及难度。清除浏览器站点数据后也需要重新导入。

## 时间版本

新练习按7∶2∶3∶3分配时间，默认50分钟，对应图形23分20秒、记忆6分40秒、空间10分钟、文字10分钟。原40分钟偏好在首次读取时迁移为50；用户仍可明确重新选择40分钟。记忆图案保持展示1秒。

新v3练习写入 `timingScheme: figure-focus-7-2-3-3`。无该字段的旧v2/v3继续按4∶2∶3∶3校验和恢复，v1继续按原均分方案。新配比不会重写旧记录或未完成进度。

## 素材边界

公开仓库和部署包只包含导入功能、通用分类与测试用微型自制PNG。下载的原题、图片、完整题包以及个人练习备份均放在仓库外。本地使用安排不等于已取得所有上游素材的公开分发许可。
