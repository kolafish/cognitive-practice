## 条件排序

对原始英文约束独立解析并穷举对象的所有排列，核对：完整条件有唯一解、所有选项中只有原答案为真。再枚举条件子集，计算推出正确选项所需的最少条件数。若正确句直接出现在原条件中，或单独一个条件已足以推出，则排除。并非只按题干长度筛选。

保留3对象249道、5对象341道、7对象406道，覆盖300个原始共享题干；共享题干的 `groupId` 保留，供练习避重复。504道直接重述或只需一个条件的题不入主练。每题的 `curationMetrics` 保存对象数、条件数、相对条件数和最少必要条件数，`originalPromptEn` 保存核验依据。

`familyLevel` 估算公式：3/5/7对象基础为1/3/5；最少必要条件每多于两个加1；全部条件为相对关系再加1；限制1–8。它反映结构工作量，没有经过儿童作答数据校准。

## 动画孔位选择

900张原答案PNG都是1250×950画布，但纸张在画布上的位置不同，且部分纸张超出画布。使用灰色纸张边界检查：842张边界完整，58张存在截断风险而排除。只有完整答案图参与选项。

将完整图按“总孔数 + 每个孔的形状/大小多重集合”分组。一个可用组至少有4种不同孔位多重集合，正确项加3个干扰项；因此四项孔数相同，孔形和大小分布也相同，仅数孔不能作答。位置集合不同的图才可互为干扰项；用位置差异和确定性哈希排序选取，重建结果可复现。

完整图中有393道满足这一条件。剩余449道同孔数、同孔形/大小的不同完整孔位不足4种，不强行凑题。最后纳入392道：2孔93道、4孔129道、8孔170道，覆盖146个不同孔位组。

对393段候选视频的全部10,563个解码帧，以250×190分辨率扫描四周2像素边界；忽略392个均匀开场帧。该步骤不是全分辨率逐帧人工核验，也不是独立物理折纸仿真。自动标出 PFHP_56 的开场帧后，人工确认其包含软件更新弹窗，显示不完整，保守排除。其他未满足图像/干扰条件的视频没有全量扫描。

`folding-choice` 使用新ID，例如 `north-fold-mentalblackboard-PFHP_1`，避免旧孔数题的历史记录误关联。旧ID保存在 `sourceQuestionId`，原题型、孔数答案、题干和原练习档位保存在 `old`，完整孔位答案保存在 `fullAnswerOriginal`，原折叠/旋转操作和打孔配置保存在 `sourceConfig`，改编规则保存在 `adaptation`。

每项都有 `image` 和 `imageCrop`，以原图内完整纸张边界加2像素余量作为SVG viewBox，不修改PNG；正确项另有一致的 `answerImageCrop`。四个选项的纸张占位因此保持相近，不靠原画布中的偏移区别答案。选项还保留 `sourceQuestionId`、`holeCount`、`holePositions` 和 `holeShapeSizes` 供复核。答案是选项ID，不能用总孔数判对。

动画题族难度独立估算为 `2×折叠数−1+旋转数+初始孔数−1`，限制1–8。静态折纸的原Level0/1/2只映射为1/4/7，不人为拆成八组；不与动画共用一条难度曲线。

## 原创词语类比

6、7、8 档各增加 12 道。6 档按顺序对应两层日常关系。7 档加入关系方向、第三项用途等近似干扰。8 档对应完整的四项关系链。每道题都提供解释。档位按题目结构估算，尚未用学生作答数据校准。原稿见 [原创词语类比](../assets/north-verbal-analogies.json)。

## 数据契约与记录兼容

所有主练题保留原字段，并新增 `taskFamily`、`taskFamilyName`、`familyLevel`、`familyLevelBasis`、`sourceQuestionId`、`curationReason`。原 `level` 和 `originalDifficulty` 不覆盖；新自适应应读取 `familyLevel`，且只在同 `taskFamily` 内调整。可用档位由 `stats.byTaskFamily.<family>.levels` 明示。

原静态选择题复用原 ID，动画改编题和原创题使用新 ID。按 ID 读取历史记录时，结合练习模式和题库版本识别当时的题目。`sources` 保留来源题的许可信息，并标出原创题的出处。

## 重建与验证

普通重建只需Python标准库，读取已提交审阅清单：

```sh
python3 scripts/build-practice-bank.py
```

重新审核现有媒体和原英文排序条件，需要Pillow、numpy、ffmpeg，以及相邻的研究目录：

```sh
python3 scripts/build-practice-bank.py --audit \
  --research ../beijing-academy-carnival-research \
  --ffmpeg /path/to/ffmpeg
```

脚本不联网。原题库SHA-256必须与审阅清单一致，否则普通重建会中止并要求重新审核。媒体路径必须是安全的 `assets/bank/` 相对路径；每个引用文件都检查存在，并按原导出文件名核对SHA-256内容哈希。

校验还覆盖主练ID唯一、所有来源题恰有一种去向、每题答案属于选项、动画四项不同孔位且孔数/孔形/大小相同、正确图与原答案图及裁剪一致、所有裁剪在源图边界内。`--audit` 和普通重建均已运行通过，普通重建输出可复现。独立的全分辨率折纸物理验证与真实作答难度校准未进行。
